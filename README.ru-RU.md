# vscode-settings \([English README](README.en-US.md)\)

Это репозиторий с настройками моего Visual Studio Code. Я стараюсь держать настройки явными, чтобы не повторять процесс настройки каждый раз, как я сношу ОС или работаю удалённо (не на своём основном ноутбуке). Кроме того, я устал вспоминать, что делает каждая настройка и почему я так настроил всё год назад.

Это вспомогательный репозиторий «для себя», а не публичный проект. В любом случае, я надеюсь, что он поможет другим, поэтому я сделал его публичным.



# Внешний `settings.json` файл

[Оказывается](https://github.com/microsoft/vscode/issues/194856), `settings.json` может быть символьной ссылкой, и VS Code будет без проблем переходить по ней. Просто перемести файл в другое место (например, в папку с проектами), пока VS Code закрыт, и создай на него ссылку:
```bash
cd ~/.config/Code/User
mv settings.json ~/projects/vscode-settings/
ln -s $HOME/projects/vscode-settings/settings.json settings.json
```
Теперь любое изменение настроек через интерфейс или в файле настроек будет появляться в этом «внешнем» файле. Их также можно менять во «внешнем» файле и VS Code будет их применять. И поскольку файл больше не находится внутри папки под управлением VS Code, его можно добавить в репозиторий (как я и сделал) или делать с ним всё что угодно.

> [!NOTE]
> Я использую один `settings.json` файл для всех профилей, поэтому такой подход работает. Если ты используешь отдельные настройки для каждого профиля, этот подход может тебе не подойти.

То же самое можно проделать с `keybindings.json`.
